# Transit Analytics Portfolio

Data analysis projects exploring public transit systems through ridership data, spatial analysis, and performance metrics.

**Author:** Aidan Moran  
**Tools:** Python (Pandas, Matplotlib, Seaborn, Folium), Jupyter, QGIS, SQL  
**Live site:** [Coming soon via GitHub Pages]

## Projects

### 1. NYC MTA Turnstile Ridership Analysis
Analyzing turnstile entry/exit data across the NYC subway system to uncover ridership patterns by time of day, day of week, and station. Includes post-pandemic recovery trends and station-level comparisons.

### 2. MARTA Ridership & Coverage (Planned)
Spatial analysis of Atlanta's MARTA system — mapping route coverage gaps, ridership density, and equity metrics using GTFS data and Census demographics.

### 3. National Transit Performance Benchmarks (Planned)
Cross-agency comparison using NTD data — cost efficiency, ridership per capita, farebox recovery, and service reliability across major U.S. transit systems.

## Project Structure

```

maps/         Exported maps and QGIS project files
docs/         GitHub Pages site files
assets/       Images, charts, and other media
```
